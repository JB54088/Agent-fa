# 官方专业目录导入包

本目录数据由 `scripts/import-official-major-directory.py` 从官方 PDF 解析生成，当前包含：

- `undergraduate-2026.json`：教育部《普通高等学校本科专业目录（2026年）》，883 条本科专业。
- `graduate-2022.json`：国务院学位委员会、教育部《研究生教育学科专业目录（2022年）》，181 条一级学科和专业学位类别。

每条目录均保留目录版本、发布机构、官方来源 URL、通知 URL、专业代码、学科门类、专业类、是否特设/国家控制布点、专业学位硕士限制等字段。

更新目录时应：

1. 从教育部或国务院学位委员会官方页面下载原始文件；
2. 使用导入脚本重新生成 JSON；
3. 校验条目数量、代码唯一性和来源 URL；
4. 在数据库 `major_sources`、`major_directory_versions`、`major_import_runs` 中记录文件哈希和导入人；
5. 新版本设为当前版本，历史版本保留，不覆盖旧专业。

系统不从第三方专业目录网站自动复制数据，也不把学校自设二级学科冒充国家统一目录。

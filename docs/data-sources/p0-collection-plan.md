# P0单位调研与采集计划

第一阶段只处理30家P0单位，不一次编写30套或100套独立爬虫。

## 调研顺序

1. 先确认单位官方主域名和招聘子域名。
2. 再确认校园招聘列表页、详情页和官方报名入口。
3. 记录robots.txt、服务条款、登录、验证码和JavaScript依赖。
4. 优先寻找公开API、RSS、PDF/XLSX/CSV附件。
5. 最后才评估静态HTML或公开JavaScript页面。

## P0单位

国家电网、南方电网、中国移动、中国电信、中国联通、中国石油、中国石化、国家能源集团、国家电投、中国电科、航天科技、航空工业、中国一汽、中国中车、中国建筑、招商局、华润、中粮、字节跳动、腾讯、阿里巴巴、京东、美团、百度、华为、小米、比亚迪、宁德时代、中国工商银行、中国建设银行。

## 验收目标

- 30家全部建立数据源档案；
- 至少20家确认官方校园招聘入口；
- 至少10家具备公开、低频、可审计的自动或半自动采集条件；
- 其余来源降级为人工录入、人工查看或公开附件导入；
- 所有发现结果进入既有的 `raw_collected_items`，并创建 `collection_review_tasks`；
- 未经审核不得创建公开 `opportunities`。

## 适配器分组

- 官方公开API/RSS：复用API/RSS适配器；
- 同类公开HTML招聘系统：复用HTML列表/详情适配器；
- 官方PDF、XLSX、XLS、CSV：复用附件适配器；
- 页面需要登录、验证码或访问限制：使用ManualSourceAdapter；
- 页面结构不稳定或无法确认官方身份：保持 `NEEDS_REVIEW`。

本文件不预填未经实际核验的URL。

# 官方入口核验目录

采集日期：2026-08-17。

本目录由 Playwright 逐条直接打开链接核验，记录最终 URL、页面标题和页面摘要。只有实际打开成功且页面可识别的入口进入 `verified`；证书错误、超时、连接失败、浏览器拦截、安全检查页及官方名录未提供链接的记录进入 `excluded`。

- `verified-official-opportunity-sites.json`：保留完整核验结果，含排除项。
- `verified-official-opportunity-sites.csv`：便于表格查看和导入。
- `website`：稳定的官方入口（使用官方名录中的原始链接，避免保存会变化的会话参数）。
- `finalUrl`：本次 Playwright 打开后到达的最终地址，仅作核验证据。

地方国企不是一个固定、有限的全国名单，本次使用可访问的省级/直辖市国资委官方入口作为地方国企发现入口；如需各地具体企业名单，应继续从这些官方目录按省市展开。生产环境批量抓取前仍需遵守目标网站的 robots.txt、服务条款和访问频率限制。

# 校招雷达数据源调研

本目录是首批100家重点单位的数据源调研台账。

## 当前阶段

- 已建立100家单位种子和100条待核验数据源档案。
- 已建立全国来源目录：国考1条、31个省考档案、央企名录入口1条、10个重点地区地方国企档案，以及香港/澳门专项档案。
- 已核验的国家/省级官方入口直接写入 `national-directory.csv`，并记录 `last_verified_at`；未实际确认的官方网站仍不写入正式招聘网址字段。
- 当前已核验国考、央企名录和31个省级公务员考试入口；地方国企和企业发现档案继续保持待复核。
- `AUTO_ALLOWED` 只能在官方域名、招聘内容、robots.txt、服务条款、登录限制和验证码情况均完成核验后使用。
- 403、429、验证码、登录要求或明确禁止自动访问的来源不得自动重试或绕过。

## 文件说明

- `organizations.csv`：100家目标单位的标准名称、类型、行业和优先级。
- `source-audit.csv`：数据源审计字段模板；空白网址代表尚未核验，不代表不存在官方入口。
- `national-directory.csv`：全国来源目录；其中已核验记录含官方URL和核验日期，空白网址是刻意保留的待核验状态，不代表已允许自动采集。
- `p0-collection-plan.md`：首批30家单位的调研和采集计划。
- `manual-sources.md`：只能人工维护或人工上传附件的来源处理规则。
- `blocked-sources.md`：明确禁止自动采集或需要人工确认的来源记录。

## 调研记录规则

每次人工核验必须记录核验日期、管理员、官方域名、页面用途、robots.txt结果、服务条款结果、登录/验证码情况和建议采集方式。任何网址变更都要保留旧值并创建数据源变更记录。
